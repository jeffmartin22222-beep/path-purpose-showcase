# Curriculum Showcase publishing policy

Only lessons with all four QA passes and evidence references may enter catalog/approved.json. Required passes: (1) independently verified content/standards, (2) pedagogy/engagement, (3) technical playback, persistence, accessibility and physical iPhone/iPad testing, (4) end-to-end student/demo. The automated validator checks manifest structure, file existence and presence of evidence references; it **does not prove** that evidence is genuine or tests passed. A human/authorized reviewer must verify evidence before merging. Do not publish teacher-only keys, private student data, protected competitor media, or unapproved work in this public repository.

The website currently remains a prototype and is not yet wired to catalog/approved.json. Hourly ChatGPT tasks do not automatically upload artifacts to GitHub. A separate authenticated ingestion path is required. No automatic merge or publication is enabled by this branch.
